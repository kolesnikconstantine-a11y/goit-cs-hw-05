# Завдання 2: Аналіз частоти слів методом MapReduce

Цей модуль реалізує багатопотокову обробку текстового контенту з мережі Інтернет за допомогою моделі програмування MapReduce.

Скрипт завантажує текст за вказаним URL, очищує його від пунктуації, приводить слова до нижнього регістру, підраховує частоту слів у кількох потоках та візуалізує Top-N найчастіше вживаних слів.

---

## Особливості реалізації

- **Завантаження даних:** отримання текстового ресурсу за допомогою бібліотеки `requests`.
- **Токенізація та нормалізація:** очищення тексту від розділових знаків та зведення всіх слів до нижнього регістру.
- **Модель MapReduce:**
  - **Map:** паралельне формування пар `(слово, 1)` для кожного слова тексту.
  - **Shuffle:** групування значень за відповідними ключами (словами).
  - **Reduce:** паралельне підсумовування кількості входжень кожного слова.
- **Багатопотоковість:** використання `concurrent.futures.ThreadPoolExecutor` для паралельного виконання етапів Map та Reduce.
- **Візуалізація:** побудова горизонтальної стовпчикової діаграми за допомогою `matplotlib` з відображенням точних значень частоти.

---

## Вимоги та встановлення

Для роботи скрипта потрібен Python 3.9+ та додаткові бібліотеки.

### 1. Перейдіть у папку завдання

```bash
cd task_2
```

### 2. Створіть та активуйте віртуальне середовище

**Linux / macOS:**

```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows:**

```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Встановіть необхідні залежності

```bash
pip install -r requirements.txt
```

Вміст файлу `requirements.txt`:

```text
requests
matplotlib
```

---

## Запуск та використання

Для запуску скрипта виконайте:

```bash
python mapreduce_words.py
```

Скрипт завантажує текст книги **"Night and Day" by Virginia Woolf** за вказаним у коді URL, виконує його обробку методом MapReduce та відображає графік із Top-10 найчастіше вживаних слів.

## Приклад візуалізації

Після завершення розрахунків відкриється вікно з графіком:

- **Вісь X:** кількість повторень (частота використання).
- **Вісь Y:** найчастіше вживані слова.
- **Числові позначки:** точна кількість входжень біля кожного стовпчика.
