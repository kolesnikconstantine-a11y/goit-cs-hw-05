# Завдання 2: Аналіз частоти слів методом MapReduce

Цей модуль реалізує асинхронну/багатопотокову обробку текстового контенту з мережі Інтернет за допомогою моделі програмування MapReduce. Скрипт завантажує текст за вказаним URL, очищує його від пунктуації, розбиває на порції (chunks), підраховує частоту слів у кількох потоках та візуалізує Top-N найвживаніших слів.

---

## Особливості реалізації

- Завантаження даних: Отримання текстових ресурсів за допомогою бібліотеки requests.
- Токенізація та нормалізація: Очищення від розділових знаків та зведення всіх слів до нижнього регістру.
- Модель MapReduce:
  - Map: Паралельне формування пар (слово, 1) для кожного блоку тексту.
  - Shuffle: Групування всіх одиниць за відповідними ключами (словами).
  - Reduce: Паралельне підсумовування кількості входжень кожного слова.
- Багатопотоковість: Використання concurrent.futures.ThreadPoolExecutor для паралельного виконання етапів Map та Reduce.
- Візуалізація: Побудова горизонтальної стовпчикової діаграми за допомогою matplotlib з автоматичним підписом точних значень.

---

## Вимоги та встановлення

Для роботи скрипта потрібен Python 3.9+ та додаткові бібліотеки.

1. Перейдіть у папку завдання:
   cd task_2

2. Встановіть необхідні залежності:
   pip install -r requirements.txt

(Вміст файла requirements.txt: requests, matplotlib)

---

## Запуск та використання

Для запуску скрипта виконайте команду:

python mapreduce_words.py

За замовчуванням скрипт завантажує текст книги "Alice's Adventures in Wonderland" із сайту Project Gutenberg, обробляє його у 4 потоки та відображає графік із Top-10 найчастіше вживаних слів.
