# Async File Sorter

Асинхронний Python-скрипт для авто-сортування файлів за їхніми розширеннями. Програма рекурсивно обходить вказану вихідну директорію та розподіляє файли по відповідних підпапках цільової директорії.

Завдяки використанню `asyncio` та обмеженню одночасного навантаження через семафор, скрипт забезпечує високу швидкість обробки великої кількості файлів без перевантаження файлової системи.

---

## Особливості

- **Асинхронна обробка:** Копіювання файлів виконується паралельно з використанням `asyncio` та `aiofiles`.
- **Контроль ресурсів:** Використання `asyncio.Semaphore` запобігає вичерпанню системних дескрипторів файлів (`Too many open files`).
- **Кросплатформеність та сумісність:** Використання `AsyncPath` та синхронного читання файлового дерева у фоновому потоці (`asyncio.to_thread`) забезпечує стабільну роботу на Python 3.10+.
- **Логування:** Підтримка виводу повідомлень у консоль та запису в лог-файл `file_sorter.log` із автоматичним фіксуванням розширеного трасування помилок (traceback).
- **Гнучке налаштування:** Керування параметрами через аргументи командного рядка (`argparse`).

---

## Вимоги

- **Python:** версії 3.10 або вище
- Додаткові бібліотеки: `aiopath`, `aiofiles`
