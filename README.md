# Домашнє завдання: Асинхронна та паралельна обробка

У цьому репозиторії представлено рішення двох практичних завдань, присвячених асинхронній та паралельній обробці даних у Python.

## Зміст

1. [Завдання 1: Асинхронне сортування файлів](https://github.com/kolesnikconstantine-a11y/goit-cs-hw-05/blob/main/task_1/README.md)

   * Рекурсивний пошук файлів та їх асинхронне сортування за розширеннями.
   * Використання `asyncio`, `aiofiles` та `asyncio.Semaphore` для ефективного копіювання файлів.

2. [Завдання 2: Аналіз частоти слів методом MapReduce](https://github.com/kolesnikconstantine-a11y/goit-cs-hw-05/blob/main/task_2/README.md)

   * Завантаження тексту за URL та аналіз частоти слів за допомогою MapReduce.
   * Використання багатопотокової обробки та візуалізація найчастіше вживаних слів.
