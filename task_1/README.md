# Task 1: Async File Sorter

Асинхронний Python-скрипт для автоматичного сортування файлів за їхніми розширеннями. Програма рекурсивно обходить вказану вихідну директорію та розподіляє файли по відповідних підпапках цільової директорії.

Скрипт використовує `asyncio` та `aiofiles` для асинхронного копіювання файлів, а `asyncio.Semaphore` обмежує кількість одночасних операцій для ефективного використання системних ресурсів.

---

## Особливості

- **Асинхронна обробка:** копіювання файлів виконується асинхронно з використанням `asyncio` та `aiofiles`.
- **Рекурсивний пошук:** програма знаходить файли у вихідній директорії та всіх її піддиректоріях.
- **Контроль ресурсів:** використання `asyncio.Semaphore` обмежує кількість одночасних операцій копіювання.
- **Копіювання блоками:** файли читаються та записуються блоками по 1 МБ, що дозволяє обробляти великі файли без завантаження всього файлу в пам'ять.
- **Фонове читання файлової системи:** `asyncio.to_thread()` використовується для виконання синхронного `os.walk()` у фоновому потоці без блокування event loop.
- **Сортування за розширенням:** для кожного типу файлів автоматично створюється окрема підпапка у вихідній директорії.
- **Логування:** повідомлення про успішні операції та помилки виводяться в консоль і записуються у файл `file_sorter.log`. Для помилок зберігається traceback.
- **Гнучке налаштування:** параметри запуску задаються через аргументи командного рядка за допомогою `argparse`.
- **Обмеження одночасних операцій:** за замовчуванням одночасно виконується не більше 10 операцій копіювання. Це значення можна змінити через `-m` або `--max-tasks`.

## Вимоги та встановлення

Для роботи скрипта потрібен Python 3.9+ та додаткові бібліотеки.

### 1. Перейдіть у папку завдання

```bash
cd task_1
```

**Linux / macOS:**

```bash
python -m venv venv
venv\Scripts\activate
```

```bash
pip install -r requirements.txt
```

Вміст файлу `requirements.txt`:

```text
aiopath
aiofiles
```

## Використання

Скрипт запускається через термінал із обов'язковим вказанням вихідної та цільової папок.

### Базовий запуск

```bash
python sort_files.py -s /path/to/source_folder -o /path/to/output_folder
```

За замовчуванням максимальна кількість одночасних операцій копіювання становить **10**.

### Запуск із налаштуванням кількості одночасних завдань

Кількість одночасних операцій можна змінити за допомогою прапорця `-m` або `--max-tasks`:

```bash
python sort_files.py -s ./downloads -o ./sorted_downloads -m 20
```

У цьому випадку одночасно буде дозволено виконувати не більше 20 операцій копіювання.

## Аргументи командного рядка

| **Аргумент** | **Повний прапорець** | **Обов'язковий** | **За замовчуванням** | **Опис** |
| ------------ | -------------------- | ---------------- | -------------------- | -------- |
| `-s` | `--source` | Так | — | Шлях до вихідної папки з файлами |
| `-o` | `--output` | Так | — | Шлях до цільової папки для відсортованих файлів |
| `-m` | `--max-tasks` | Ні | 10 | Максимальна кількість одночасних операцій копіювання |
| `-h` | `--help` | Ні | — | Довідка з використання скрипта |

## Структура результату

Файли сортуються у підпапки цільової директорії відповідно до їхніх розширень.

Наприклад:

```text
source/
├── document.pdf
├── photo.jpg
├── archive.zip
└── subfolder/
    └── report.pdf

output/
├── pdf/
│   ├── document.pdf
│   └── report.pdf
├── jpg/
│   └── photo.jpg
└── zip/
    └── archive.zip
```

Файли без розширення поміщаються до підпапки `no_extension`.
