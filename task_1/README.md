# Async File Sorter

Асинхронний Python-скрипт для авто-сортування файлів за їхніми розширеннями. Програма рекурсивно обходить вказану вихідну директорію та розподіляє файли по відповідних підпапках цільової директорії.

Завдяки використанню asyncio та обмеженню одночасного навантаження через семафор, скрипт забезпечує високу швидкість обробки великої кількості файлів без перевантаження файлової системи.

---

## Особливості

- Асинхронна обробка: Копіювання файлів виконується паралельно з використанням asyncio та aiofiles.
- Контроль ресурсів: Використання asyncio.Semaphore запобігає вичерпанню системних дескрипторів файлів (Too many open files).
- Кросплатформеність та сумісність: Використання AsyncPath та синхронного читання файлового дерева у фоновому потоці (asyncio.to_thread) забезпечує стабільну роботу на Python 3.10+.
- Логування: Підтримка виводу повідомлень у консоль та запису в лог-файл file_sorter.log із автоматичним фіксуванням розширеного трасування помилок (traceback).
- Гнучке налаштування: Керування параметрами через аргументи командного рядка (argparse).

## Вимоги та встановлення

Для роботи скрипта потрібен Python 3.9+ та додаткові бібліотеки.

1. Перейдіть у папку завдання:
   cd task_1

2. Створіть та активуйте віртуальне середовище (рекомендовано):

Linux / macOS:
python3 -m venv venv
source venv/bin/activate

Windows:
python -m venv venv
venv\Scripts\activate

3. Встановіть необхідні залежності:
   pip install -r requirements.txt

(Вміст файла requirements.txt: aiopath, aiofiles)

## Використання

Скрипт запускається через термінал із обов'язковим вказанням вихідної та цільової папок.

### Базовий запуск

python sort_files.py -s /path/to/source_folder -o /path/to/output_folder

### Запуск із налаштуванням кількості одночасних завдань

За замовчуванням кількість одночасних операцій копіювання обмежена 10. Ви можете змінити цей параметр за допомогою прапорця -m або --max-tasks:

python sort_files.py -s ./downloads -o ./sorted_downloads -m 20

---

## Аргументи командного рядка

| Аргумент | Повний прапорець | Обов'язковий | За замовчуванням | Опис |
| :--- | :--- | :---: | :---: | :--- |
| -s | --source | Так | — | Шлях до вихідної папки з файлами |
| -o | --output | Так | — | Шлях до цільової папки для відсортованих файлів |
| -m | --max-tasks | Ні | 10 | Максимальна кількість одночасних операцій копіювання |
| -h | --help | Ні | — | Довідка з використання скрипту |
